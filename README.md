# 一株植物的株 · Plant observation archive

从一株植物，认识一片自然。这里收录植物与真菌的实地观察，用照片、观察笔记、自然手绘和视频记录它们的形态与生活。

Follow field observations of plants and fungi through photographs, notes, drawings and videos. Each record follows the subject of one video.

[浏览中文网站](https://yizhuzhiwudezhu.github.io/plant-atlas/?lang=zh) · [Visit the English site](https://yizhuzhiwudezhu.github.io/plant-atlas/?lang=en)

## 本地浏览 · Local preview

本仓库保存 GitHub Pages 使用的静态网站。在仓库根目录运行下面的命令后，用浏览器打开本地首页。

This repository contains the static site served by GitHub Pages. Run the following command from the repository root, then open the local homepage.

```sh
python -m http.server 8000
```

[本地首页 · Local homepage](http://localhost:8000/)
